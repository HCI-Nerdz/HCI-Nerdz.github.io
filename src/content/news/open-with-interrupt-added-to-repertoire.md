Open-with interrupt entered the repertoire: a proposed first-class gesture that stops default file-handler handoff and asks which app should open *this* file *now*.

Across Windows, macOS, and major Linux file managers, Open with still lives in context menus and property sheets. Ctrl+double-click and middle-click on files are largely unused for that job.
