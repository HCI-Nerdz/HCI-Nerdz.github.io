Context Edge entered the repertoire: ecosystem navigation as a **substrate at the edges**, not subsection tabs painted across the content header.

Hover expands a thin rail; click opens a wireframe map between platforms. Each subplatform keeps a stable color overlay so you can tell which world is active without relearning the entrypoint chrome.
