Spatial web windows entered the repertoire: physically separated lite palettes wired to a shared viewport — the remote-control pattern for professional web apps, without reimplementing windowing inside a canvas.

The record covers platform primitives (Document PiP, chromeless popups, SharedWorker hubs), intent routing instead of viewport-width traps, and browser-level gaps tracked in a Chromium fork.
