== Structure

* Landing page, philosophy, news feed, blog essays (separate content collections + RSS), and `/demos/` index
* Links to Antora docs at `https://hci-nerdz.github.io/docs/`

News = org updates. Blog = essays. Demos = interactive prototypes by category (including instruction flows under attention / progressive disclosure).

Authoritative conversation sources for concepts (e.g. Scoped UX) live in the docs repo under `literature/` — see link:https://hci-nerdz.github.io/docs/hci-nerdz/literature.html[Literature].
