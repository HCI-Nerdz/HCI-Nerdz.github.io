= 2026-10-27 — CSS styles chain demo

* `/demos/css-styles-chain/` lists properties that apply to the element you pick, with an editable value for prototyping.
* Each property is a chain: red for an `!important` declaration that lost, green for the one in effect, grey for ordinary and inherited declarations that lost.
* The element tree is separate from that chain. Clicking a crumb lights the ancestors that selector requires.
* The front door opens three views: the inspector, the sample page, and the in-page layout.
* The inspector reads the sample page’s stylesheets. A class button opens only that rule. The triangle at the end of the line opens every class on the property.
* Light and dark sit in a fixed bar at the bottom of the inspector. That switch changes the page being read.
* The demo introduction starts from the Styles pane: struck lines that look right, no link to the winner, and the computed-value jump.
